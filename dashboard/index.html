How this radar works — the model, in the open

Implied value = category multiple × TVL0.85 × growth × maturity. The category multiple is the median market-cap / TVL of the live-token protocols in the same category (small samples are shrunk toward the global median) — so a lending protocol is priced like lending protocols trade, not like a bridge. TVL enters sublinearly (exponent 0.85): size matters, but a $2.7B protocol is not 100× a $27M one. Growth is the 7-day TVL change, clamped to −50%…+100% and weighted 0.6. Maturity rises with how long a protocol has run with no token (0.70 at launch, saturating near 1.00 after ~3 years; 0.85 when the listing date is unknown). No protocol name is ever special-cased — the same function scores every row.

Implied value is this entry's own claim about what a token would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued. A protocol is called “pre-token” when its DefiLlama record carries no token — the record is not proof it has none. Snapshot as of .
